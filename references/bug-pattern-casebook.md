# 버그 패턴 사례집 — 파트·언어별 흔한 결함

추론의 **근거(exemplar)**다. 발동 트리거가 아니다(`reasoning-method.md` 원칙 2). 변경의 구조를 가장 가까운 패턴에 사상해 번역하고, 적대적 검증으로 거짓양성을 거른다. 언어 이름이 아니라 **구조**로 매칭한다.

---

## 보편 (모든 파트)

| 패턴 | 구조 | 흔한 발현 |
|---|---|---|
| off-by-one | 경계 인덱스 | `<=` vs `<`, `length` 접근, 슬라이스 끝 |
| null 전파 | 옵셔널 미처리 | 중간 null이 끝까지 흘러 늦게 터짐 |
| check-then-act | 비원자 읽기-쓰기 | `if !exists: create` 동시 진입 → 중복/레이스 |
| 자원 누수 | 예외 경로 미해제 | 파일·커넥션·락이 throw 시 안 닫힘 |
| 삼킨 예외 | 빈 catch | 실패가 묻혀 잘못된 정상 처리 |
| 부동소수 비교 | `==` on float | 누적 오차, 통화 계산 |
| 가변 공유 | 참조 공유·가변 디폴트 | 한 곳 변경이 다른 곳 오염 |
| 시간대·DST | 로컬/UTC 혼용 | 자정·DST·윤년·통화 단위 |

## 🖥 백엔드

| 패턴 | 발현 |
|---|---|
| 멱등성 부재 | 재시도·웹훅 재전송·더블클릭 → 이중 결제/생성 |
| 트랜잭션 경계 오류 | 외부 IO를 트랜잭션 안/밖 잘못 둠, 부분 커밋 |
| 격리수준 가정 | 더티리드·팬텀·lost update, `SELECT FOR UPDATE` 누락 |
| N+1 | 루프 내 쿼리, lazy 로딩 폭발 |
| 커넥션 누수 | 풀 반환 누락 → 고갈, 트랜잭션 미커밋 |
| IDOR | 객체 id 소유자 미확인 |
| 페이지네이션 부재 | 전체 로드로 메모리·지연 폭발 |
| 마이그레이션 비가역 | 롤백 없음, 무중단 중 구·신 충돌 |
| 캐시 무효화 | stale, write-after-read, 캐시 스탬피드 |

## 🌐 프론트엔드

| 패턴 | 발현 |
|---|---|
| stale closure | 오래된 클로저가 옛 state/props 참조 |
| useEffect 의존성 | 누락→안 갱신, 과다→무한 루프, cleanup 누락→누수 |
| 응답 race | 빠른 연속 요청 응답 역전(취소 안 함) |
| 리렌더 폭발 | 인라인 객체/함수·키 누락·메모 부재 |
| 구독 누수 | 리스너·타이머·소켓 cleanup 누락, 언마운트 후 setState |
| XSS | 미이스케이프 입력 렌더, `dangerouslySetInnerHTML` |
| UI 상태 누락 | 로딩·빈·에러·부분 미처리 |
| 접근성 | alt·라벨·포커스·대비·ARIA 누락 |

## 🤖 Android

| 패턴 | 발현 |
|---|---|
| Context 누수 | Activity 참조 정적/장기 보유 → 메모리 누수 |
| 생명주기 상태소실 | 화면 회전·재생성 시 상태 날아감 |
| 메인스레드 블로킹 | UI 스레드 IO/DB → ANR |
| GlobalScope | 코루틴 스코프 누수·취소 안 됨 |
| `!!` 강제 언래핑 | 플랫폼 타입 null → 크래시 |
| Flow 수집 생명주기 | `repeatOnLifecycle` 없이 백그라운드 수집 |
| exported 컴포넌트 | 검증 없는 인텐트·딥링크 |

## 🍎 iOS

| 패턴 | 발현 |
|---|---|
| retain cycle | 클로저 `self` 강참조, 델리게이트 strong → 누수 |
| 옵셔널 강제 언래핑 | `!`·`as!` → 크래시 |
| 백그라운드 UI 갱신 | 메인 스레드 아닌 곳에서 UI → 크래시·글리치 |
| Combine 구독 해제 | `AnyCancellable` 미보관 → 즉시 해제 |
| 데이터 레이스 | actor/큐 격리 위반, `@MainActor` 누락 |
| 앱 생명주기 | background 전이 시 자원 미정리 |

## 🧠 AI/ML

| 패턴 | 발현 |
|---|---|
| 데이터 누수 | split 전 전처리 fit, 타깃 누수, 시계열 미래 유입 |
| 시드 미고정 | 재현 불가, 비결정 |
| NaN/Inf 전파 | `log(0)`·0 나눗셈·overflow → 조용한 오염 |
| 차원·브로드캐스팅 | 조용히 잘못된 결과(안 죽음) |
| 지표 오용 | 불균형에 accuracy, 누수된 검증, 잘못된 평균 |
| 프롬프트 인젝션 | 사용자 입력이 시스템 프롬프트 오염 |
| 출력 무검증 실행 | LLM 출력 코드/SQL 직접 실행 |
| 비용·토큰 폭증 | 배치·캐시 미사용, 동기 직렬 호출 |
| 학습-서빙 skew | 전처리 불일치 |

---

각 패턴의 수치·관행은 사례일 뿐 정답이 아니다. 해당 코드 맥락(동시성 보장·신뢰 경계·규모)에 맞게 번역해 적용하고, 조건이 안 맞으면 "– 무관(사유)"으로 뺀다.
