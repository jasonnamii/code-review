# 레드플래그 자동 스크리너 — P0 코드 재앙 카탈로그

**Phase 1(8축 정밀검사) 전에 변경을 이 카탈로그에 1차 통과**시킨다. 걸리면 무조건 P0 후보로 선등록 — 8축 결과와 무관하게 먼저 띄운다. "안 막으면 사고 나는" 치명 패턴만 모았다. 파트별 추가 레드플래그는 `part-lens.md`.

## 사용법
변경의 각 신호를 R1~R20에 관련성 판정(●○-)으로 통과. 걸린 항목은 `🟥 [REDFLAG-Rxx / P0]`로 선등록 + 최소 처방. **중대(🔴)/주의(🟠)** 태깅. **단, 적대적 검증 필수** — 패턴이 보여도 맥락상 안전하면(외부 입력 없음·단일 스레드·이미 검증됨) 사유와 함께 제외(`reasoning-method.md` 원칙 4·5).

## 보편 코드 레드플래그 (R1~R14)

| # | 신호 | 왜 치명 | 최소 처방 |
|---|---|---|---|
| R1 🔴 | 외부 입력이 쿼리·명령·코드로 문자열 조립 | SQL/명령/코드 **인젝션** | 파라미터 바인딩·이스케이프·allowlist |
| R2 🔴 | 권한 체크가 클라이언트·화면에만 | 권한 우회·수평/수직 상승·IDOR | 서버 매 호출 재검증, 없음=404 |
| R3 🔴 | 결제·생성·전송에 멱등성·중복 방지 없음 | 재시도·더블클릭으로 **이중처리** | 멱등키 + 유니크 제약 |
| R4 🔴 | 공유 자원(잔액·재고·카운터) 동시 접근 비원자 | 레이스 → 음수·초과·더블부킹 | 원자적 조건부 업데이트·락·트랜잭션 |
| R5 🔴 | 다단계 쓰기에 부분실패 보상 없음 | 일부 성공+실패 = 데이터 불일치 | 트랜잭션·보상(롤백)·아웃박스 |
| R6 🔴 | 데이터 삭제·덮어쓰기가 즉시·비가역 | 오삭제 복구 불가·데이터 손실 | soft delete·백업·확인·유예 |
| R7 🔴 | 비밀(키·토큰·비번)이 코드·로그·커밋에 | 비밀 유출 | 비밀 제거·시크릿 매니저·키 로테이션 |
| R8 🔴 | 자원(커넥션·파일·락·구독)이 예외 경로에서 안 닫힘 | 누수 → 고갈·행·OOM | `finally`/`defer`/`with`/RAII·cleanup |
| R9 🟠 | 예외를 빈 catch로 삼킴 | 실패가 조용히 묻혀 잘못된 결과 | 다시 던지거나 결과로 신호·로깅 |
| R10 🟠 | 외부 호출에 타임아웃·재시도 백오프 없음 | 행·thundering herd·장애 증폭 | 타임아웃 + 지수 백오프 + 지터 + 서킷 |
| R11 🟠 | 공개 API·스키마·직렬화 하위호환 깸 | 기존 클라이언트·데이터 깨짐 | 버전·디폴트·단계적 마이그레이션 |
| R12 🟠 | 스키마/데이터 마이그레이션에 롤백 없음 | 배포 실패 시 복구 불가 | 역마이그레이션·무중단(구·신 공존) |
| R13 🟠 | 루프 안에서 쿼리·네트워크 호출(N+1) | 대용량에서 성능 붕괴 | 배치·조인·캐시·프리페치 |
| R14 🟠 | 무한 루프·무한 대기·재귀 종료 조건 모호 | 행·스택오버플로 | 종료 조건·상한·타임아웃 명시 |

## 출력 형식 (Phase 1 선행)
```
## 🚨 레드플래그 선행 스캔 (8축 검사 전)
🔴 REDFLAG-R1 [P0] cache.ts:42 — 사용자 입력으로 SQL 문자열 조립 → 인젝션
  최소 처방: 파라미터 바인딩으로 변경
  (적대적 검증: 입력이 정수 강제변환됨? → 확인 결과 문자열 그대로 → 결함 확정)
🔴 REDFLAG-R8 [P0] handler.go:88 — 에러 경로에서 DB 커넥션 미반환 → 풀 고갈
🟠 REDFLAG-R13 [P1] list.tsx:120 — 렌더 루프 내 fetch → N+1
─────────────────
선행 스캔: 🔴 중대 2건 · 🟠 주의 1건. 8축 정밀 검사로 진행.
```

레드플래그 🔴 중대 1건이라도 걸리면 웨이트 게이트에서 **라이트 선택을 경고**한다(치명 패턴을 덮으면 안 됨). 보안·동시성·마이그레이션 연루면 헤비 권장.
